## 🎨 Design Highlights

- **Dark glassmorphism** — deep navy background with frosted glass cards (`backdrop-filter: blur`)
- **Cyan & purple accent palette** — `#00e5ff` (cyan) and `#9f6cff` (purple) for a premium developer feel
- **Radial gradient mesh** — subtle ambient glow layered as a fixed background element
- **Noise texture overlay** — SVG fractal noise at low opacity for depth
- **Scroll-reveal animations** — `IntersectionObserver`-powered fade-up entrance for every section
- **Staggered card animations** — sibling cards animate in with increasing `transition-delay`
- **Spinning avatar ring** — CSS `@keyframes` dashed orbit ring around the profile image
- **Responsive hamburger nav** — mobile-first slide-in menu with animated icon morph

## 🚀 Running Locally

No build step needed. Just open the file directly in your browser:

```bash
# Clone the repo
git clone https://github.com/sh4on/sh4on.github.io.git
cd sh4on.github.io

# Open in browser (Linux)
xdg-open index.html

# Or serve with Python (optional, for live reload feel)
python3 -m http.server 8080
# then visit: http://localhost:8080
```

## 🌐 Deployment

This site is deployed automatically via **GitHub Pages** from the `main` branch.

- Push any changes to `main` and GitHub Pages will serve the updated version within seconds.
- The custom domain `www.shaonx.com` is configured via the `CNAME` file in the repo root.

```bash
# Deploy changes
git add .
git commit -m "update: <your change description>"
git push origin main
```
